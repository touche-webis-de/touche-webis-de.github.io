  • Rankings per track (base / enhanced)

This page lists the official results of the Fallacy Detection task at Touché 2026. Runs are ranked by macro F1-score; precision and recall are macro-averaged as well. For Sub-Task 3, the two label dimensions (argument goal and argument basis) are scored separately; the macro average runs over the four dimension classes. The Tag column indicates whether a system used only the original (base) fields or also the enhanced fields; base and enhanced runs are ranked separately per sub-task, followed by a combined ranking. The Repaired column marks broken runs: entries for which the run submitted no prediction or an invalid label were counted as incorrect (the column states how many predictions were affected). Runs marked as “not ranked (informational)” exceeded the submission limit or were submitted by organizers and are reported for reference only.
